# Owner-supplied demo evidence

`owner_demo_packet.json` preserves the supplied
`sc_01m678rq8awba53pxwhrjftdyp-evidence.json` byte-for-byte. Its checksum and
scope are in [manifest.json](manifest.json).

This is a **synthetic, simulation-only** campaign, revision 50, with twelve
fictional vehicles and zero investigation drafts. It documents the earlier
walkthrough's state and events. It is separate from the later 213-owner EPS
walkthrough, classifier human-review exports and live Meta proof files.

The packet's `metrics` describe fictional recorded activity. They do not count
real warnings delivered, real study participants, field repairs or accidents
prevented. The original export is preserved for inspection rather than
regenerated with new outcomes.
