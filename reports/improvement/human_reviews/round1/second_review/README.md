# Second human review

Open [second_review.html](second_review.html) in a browser, or send that HTML file to the second reviewer. It works offline and contains only the assigned complaints and label choices.

A different person should independently complete all 50/50 assigned complaints. For each complaint, choose a supported label and record supporting words and uncertainty in notes. The reviewer enters their own name, confirms independent human review, and clicks **Export reviewed labels**. The download is `defect-second-review.json`. Partial exports can save progress, but the gate needs the complete 50/50 assignment.

Return the downloaded JSON for validation and agreement analysis before human adjudication and accuracy scoring. Your first review stays preserved separately.

The [pre-registered ID list](preregistered_ids.json) was fixed before this page was opened. These records remain evaluation-only; no fitting, calibration, feature selection, or dashboard accuracy.
