Why it is pathologically slow
-----------------------------

  5000 x 5000 Python list and calls cosine() for every pair:
  5,000 * 4,999 / 2 = 12,497,500 pairs.
- cosine() is pure Python and converts/loops over all 512 dimensions
  (src/ml_runtime/embeddings.py:312-330).
- select_k() repeats silhouette for each k in 2..5.
- This is a test/product performance issue, not a functional assertion
  failure. No threshold, regex, lexicon, test or product code was changed
  to make it pass.
