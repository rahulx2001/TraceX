Live investigation task study

This study compares the full existing record-review workflow, extraction-only assistance and the sourced investigation loop on the same task set. Each participant sees a task once. A separately attested material-fact rubric was frozen before participation.

Time starts before the task is revealed and includes opening the app, live model waiting, lookups, corrections and review. This page does not call a model or submit judgments. Actual run exports and independent grading are required for analysis. Do not count a saved replay as a live run.

Record the phase when you change activity. These are participant-marked events, not provider latency measurements.
